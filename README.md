I am a **business developer and investment manager** with a focus on finance, financial modelling, investment analysis and data-driven decision-making. My interests include quantitative finance, portfolio optimisation, econometrics and the practical use of AI in financial research.

## Building for open access

My current open-source project is **Alireza - MT5 Trade & Risk Manager**: a configurable workspace for personal checklists, position planning, emotion review, chart tools and local journaling.

The project is available under the MIT license. My aim is to reduce the software-cost barrier and let users adapt the tool to their own trading process. The public preview includes seven core UI languages with documented translation limits.
